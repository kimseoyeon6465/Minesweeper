# Minesweeper - C++ 콘솔 지뢰찾기

2차원 맵 구조와 사용자 입력을 기반으로 상태 변화를 처리하는 C++ 콘솔 지뢰찾기 프로그램입니다.

- YouTube: https://www.youtube.com/watch?v=CK9b8Uc0fAY
- 포트폴리오: https://github.com/kimseoyeon6465/Portfolio

| 항목 | 내용 |
|---|---|
| 기간 | 2022.10 |
| 인원 | 1명 (개인 프로젝트) |
| 기술 | C++, WinAPI (콘솔 애플리케이션) |

## 주요 기능

- 1차원 배열로 2차원 보드를 처리하는 맵 데이터 생성과 8방향 인접 상태 계산
- WinAPI 입력 이벤트 처리와 입력 좌표의 배열 인덱스 변환
- DFS 재귀 탐색으로 인접한 빈 영역 자동 오픈
- 상태 관리와 종료 조건 판별

## 핵심 구현

- **맵 구조:** 1차원 배열 하나로 2차원 보드를 다루고, 좌표를 인덱스로 변환해 8방향 인접 칸의 상태를 계산합니다.
- **빈 영역 자동 오픈:** DFS 재귀로 인접한 빈 영역을 한 번에 엽니다.
- **중복 처리 방지:** 방문 여부와 처리 상태를 배열로 나누어 관리합니다.

## 트러블슈팅

| 문제 상황 | 원인 분석과 시도 | 해결 결과 |
|---|---|---|
| DFS 재귀 탐색에서 무한 재귀가 발생해 프로그램이 멈춤 | 조건 하나를 고치는 방식으로 해결되지 않아, 호출마다 상태와 좌표 변화를 단계별로 추적. 종료 조건이 분기되지 않아 같은 영역을 반복 검사하는 것을 확인 | 종료 조건을 분리하고, 방문 여부와 처리 상태를 배열 2개로 나누어 관리해 해결 |
